# pi-pr-review-goal

Private Pi package providing the `/pr-review-goal` extension.

## Install

```bash
pi install git:github.com/matifuentes2/pi-pr-review-goal
```

## Command

```bash
/pr-review-goal <pr-number>
```

Starts a Codex-style PR review/fix/comment loop for a GitHub PR targeting `develop` or `dev`.
